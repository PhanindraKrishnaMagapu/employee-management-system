# Employee Management System - Documentation

## Overview
This folder contains the project documentation. The database, API, and browser
UI for employee records, hierarchy, JML, projects, skills, and salary are
implemented. The latest reported full backend verification is **287 passed,
0 failed**; see the [setup guide](setup-guide.md#6-run-automated-database-tests)
for the test command and coverage summary.
